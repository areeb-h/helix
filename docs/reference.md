## Free functions

## assert

### `assert(condition, message?)`

Raise a catchable error unless the condition is true; a missing condition also fails.

```
>>> assert(n > 0, "n must be positive")
```

### `assert_close(a, b, tol?)`

Raise unless two numbers are within tol (default 1e-9) of each other.

```
>>> assert_close(0.1 + 0.2, 0.3)
```

### `assert_eq(a, b)`

Raise unless the two values are equal, showing both sides in the error.

```
>>> assert_eq(2 + 2, 4)
```

### `assert_error(try_result, substring?)`

Raise unless a `try` FAILED — and, given a substring, unless its message contains it.

**Note:** Shows the actual message when it does not match, and the VALUE when the expression succeeded instead — the plain `assert(r.error.contains(...))` idiom shows neither.

```
>>> assert_error(try raise("bad input"), "bad")
```

### `raise(message, help?)`

Raise an error with a message and optional help line; caught by try like any error.

```
>>> raise("k must be positive", "pass k >= 1")
```

## autodiff

### `gradient(loss, x)`

Reverse-mode gradient of the scalar loss w.r.t. leaf x (or an array of leaves).

**Note:** x must be the SAME variable(...) leaf used in loss; a fresh leaf reads 0.0.

```
>>> gradient(x * x, x)
```

### `value_of(x)`

The forward (plain) value of a tracked value; a plain value passes through.

```
>>> value_of(variable(2.0))

```

### `variable(x)`

Wraps a number or tensor as a tracked autodiff leaf for gradient().

```
>>> variable(2.0)
2.0
```

## crypto

### `aes_decrypt(key, ciphertext)`

Decrypt aes_encrypt output; a wrong key or tampered ciphertext raises.

```
>>> aes_decrypt("413811a542a07328643c662446279e7d265bd2211b88a687b254adfb15479396", "dJITnntJq8pZkeHmuxcFMD/HMls5dZWj4pftlbzx")
hi
```

### `aes_encrypt(key, plaintext)`

AES-256-GCM encrypt under a 64-hex key — base64 of nonce + ciphertext + tag.

**Note:** Fresh random nonce per call: the same key and plaintext give a DIFFERENT ciphertext each time.

```
>>> aes_encrypt(aes_keygen(), "attack at dawn")
```

### `aes_keygen()`

A fresh random AES-256 key, as 64 hex chars.

```
>>> aes_keygen()
```

### `ed25519_keygen()`

A fresh Ed25519 keypair record {private, public} (hex).

**Note:** fresh randomness each call — a run is not reproducible; store keys, never regenerate.

```
>>> ed25519_keygen().keys()
```

### `ed25519_sign(private, message)`

Sign a message with the PRIVATE key (key first); the signature is hex.

**Note:** argument order is (key, message) — the sweep found the docs had it reversed.

```
>>> ed25519_sign(ed25519_keygen().private, "msg").length()
```

### `ed25519_verify(public, message, signature)`

Verify a signature (public key first); answers a Bool, never raises on a bad one.

```
>>> ed25519_verify(kp.public, "msg", sig)
```

## db

### `sqlite_query(path, sql, params?)`

Run a read-only SQL query against a SQLite file and return the rows as a DataFrame.

**Note:** Opens READ-ONLY, so the fs-read capability label is the truth and a typo in the path fails instead of creating an empty database. Parameters bind as VALUES to `?`; there is no way to splice text into the statement, which is what makes injection unrepresentable rather than merely discouraged.

```
>>> sqlite_query("app.db", "select name from users where age > ?", [30])
```

## encoding

### `base64_decode(b64)`

Decode standard base64 back to text; invalid base64 raises.

**Note:** Decodes to TEXT — base64 of non-UTF-8 binary raises; Helix strings are text, not bytes.

```
>>> base64_decode("SGVsaXg=")
Helix
```

### `base64_encode(text)`

Standard base64 (with padding) of the string's UTF-8 bytes.

```
>>> base64_encode("Helix")
SGVsaXg=
```

### `hex_decode(hex)`

Decode a hex string (an even count of 0-9a-f digits) back to text.

**Note:** Decodes to TEXT — hex of non-UTF-8 bytes raises; Helix strings are text, not bytes.

```
>>> hex_decode("486921")
Hi!
```

### `hex_encode(text)`

Lowercase hex of the string's UTF-8 bytes.

```
>>> hex_encode("Hi!")
486921
```

### `url_decode(text)`

Decode percent escapes back to text — the strict inverse of url_encode.

**Note:** RAISES on a malformed percent escape (and a non-UTF-8 result); url_decode_lenient never raises.

```
>>> url_decode("caf%C3%A9%20au%20lait")
café au lait
```

### `url_decode_lenient(text)`

Percent-decode for untrusted input; malformed escapes stay literal.

**Note:** Never raises on any string: a bad % stays literal, non-UTF-8 decodes with replacement chars.

```
>>> url_decode_lenient("100% sure")
100% sure
```

### `url_encode(text, set?)`

Percent-encode the UTF-8 bytes (RFC 3986); a set name ("query", ...) keeps more chars.

```
>>> url_encode("café au lait")
caf%C3%A9%20au%20lait
```

### `count()`

The total number of elements across all dimensions.

```
>>> tensor([[1.0, 2.0], [3.0, 4.0]]).count()
4
```

### `det()`

The determinant of a square 2-D tensor.

```
>>> tensor([[1.0, 2.0], [3.0, 4.0]]).det()
-2.0
```

### `dot(other)`

Alias of matmul: the vector dot product, or the matrix product.

```
>>> tensor([1.0, 2.0]).dot(tensor([3.0, 4.0]))
11.0
```

### `flatten()`

All elements as a 1-D tensor, in row-major order.

```
>>> tensor([[1.0, 2.0], [3.0, 4.0]]).flatten()
[1, 2, 3, 4]
```

### `inv()`

The inverse of a square 2-D tensor; errors if the matrix is singular.

```
>>> tensor([[2.0, 0.0], [0.0, 4.0]]).inv()
[[0.5, 0],
 [0, 0.25]]
```

### `matmul(other)`

Matrix multiply: vec.vec is a scalar dot; mat.mat and mat.vec give tensors.

```
>>> tensor([[1.0, 2.0], [3.0, 4.0]]).matmul(tensor([[1.0, 0.0], [0.0, 1.0]]))
[[1, 2],
 [3, 4]]
```

### `max(axis?)`

The largest element, or the maxima along the given axis.

```
>>> tensor([[1.0, 2.0], [3.0, 4.0]]).max()
4.0
```

### `mean(axis?)`

The mean of all elements, or the means along the given axis.

```
>>> tensor([[1.0, 2.0], [3.0, 4.0]]).mean()
2.5
```

### `min(axis?)`

The smallest element, or the minima along the given axis.

```
>>> tensor([[1.0, 2.0], [3.0, 4.0]]).min()
1.0
```

### `ndim()`

The number of dimensions: 1 for a vector, 2 for a matrix.

```
>>> tensor([[1.0, 2.0], [3.0, 4.0]]).ndim()
2
```

### `norm()`

The Euclidean (L2) norm: sqrt of the sum of squared elements.

```
>>> tensor([3.0, 4.0]).norm()
5.0
```

### `reshape(shape)`

The same elements in a new shape; the element counts must match.

```
>>> tensor([[1.0, 2.0], [3.0, 4.0]]).reshape([4])
[1, 2, 3, 4]
```

### `shape()`

The dimension sizes as an array: [rows, cols] for a matrix.

```
>>> tensor([[1.0, 2.0], [3.0, 4.0]]).shape()
[2, 2]
```

### `softmax(axis?)`

Numerically stable softmax along an axis (default: the last).

```
>>> tensor([0.0, 0.0]).softmax()
[0.5, 0.5]
```

### `solve(b)`

Solve A x = b for x (b a vector or matrix); errors if A is singular.

```
>>> tensor([[2.0, 0.0], [0.0, 4.0]]).solve(tensor([2.0, 8.0]))
[1, 2]
```

### `sum(axis?)`

The sum of all elements, or the sums along the given axis.

```
>>> tensor([[1.0, 2.0], [3.0, 4.0]]).sum()
10.0
```

### `t()`

Shorthand for transpose(): axes reversed.

```
>>> tensor([[1.0, 2.0], [3.0, 4.0]]).t()
[[1, 3],
 [2, 4]]
```

### `transpose()`

The tensor with its axes reversed: rows become columns.

```
>>> tensor([[1.0, 2.0], [3.0, 4.0]]).transpose()
[[1, 3],
 [2, 4]]
```

## DataFrame methods

### `cache()`

Materialize once in memory so later verbs reuse it without re-scanning.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).cache().count()
2
```

### `column(name)`

One column's values as an array.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).column("a")
[1, 2]
```

### `columns()`

The column names, as an array of strings.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).columns()
["a", "b"]
```

### `count()`

The number of rows.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).count()
2
```

### `drop_missing()`

Keep the rows where every column is non-missing.

**Note:** Does not remove NaN — a failed computation is not absent data. Use drop_nan().

```
>>> dataframe({a: [1, missing], b: [3.0, 4.5]}).drop_missing().count()
1
```

### `drop_nan()`

Keep the rows where no column holds a NaN.

**Note:** The opt-out from NaN propagation. A column that cannot hold a NaN (Int, String, Bool) never excludes a row. Does not remove missing.

```
>>> dataframe({v: [1.0, nan, 3.0]}).drop_nan().count()
2
```

### `filter(predicate)`

Alias of where: keep the rows where the predicate is true.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).filter(@b < 4.0).count()
1
```

### `group(@col, ...)`

Group rows by key column(s) for mean/sum/min/max/count/std aggregation.

```
>>> dataframe({k: ["a","a","b"], v: [1,2,3]}).group(@k).sum(@v).count()
2
```

### `head(n)`

The first n rows.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).head(1).count()
1
```

### `join(other, @key, ..., how?)`

Join with another frame on key column(s); a trailing string picks the type.

```
>>> dataframe({id: [1, 2], x: [10, 20]}).join(dataframe({id: [2], y: [5]}), @id).count()
1
```

### `select(@col, ...)`

A frame with only the named columns, in the given order.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).select(@a).columns()
["a"]
```

### `sort(@col, ...)`

Rows sorted ascending by the named column(s).

**Note:** Missing rows sort FIRST here — unlike Array sort, which refuses missing.

```
>>> dataframe({a: [2, 1], b: [3.0, 4.5]}).sort(@a).column("a")
[1, 2]
```

### `to_html()`

The frame as a complete styled HTML document, returned as a string.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).to_html()
```

### `to_markdown()`

The frame as a Markdown table string (numeric columns right-aligned).

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).to_markdown()
| a | b |
| ---: | ---: |
| 1 | 3.0 |
| 2 | 4.5 |
```

### `to_table()`

The frame as an aligned plain-text table string.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).to_table()
a    b
-  ---
1  3.0
2  4.5
```

### `unique(key?, ...)`

Drop duplicate rows; with key columns, keep one row per key combination.

**Note:** With keys the LAST duplicate wins (upsert-style), not the first-seen row.

```
>>> dataframe({a: [1, 1, 2]}).unique().count()
2
```

### `vstack(other)`

Append another frame's rows below this one (same columns).

```
>>> dataframe({a: [1, 2]}).vstack(dataframe({a: [3]})).count()
3
```

### `where(predicate)`

Keep the rows where the predicate over @columns is true.

**Note:** Comparing with missing yields missing: where(@v == missing) selects NO rows — use drop_missing.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).where(@a > 1).count()
1
```

### `with({name: expr, ...})`

Add or replace columns computed from expressions over existing columns.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).with({c: a + b}).columns()
["a", "b", "c"]
```

### `write_csv(path)`

Write the frame to a CSV file at path.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).write_csv("out.csv")
```

### `write_json(path)`

Write the frame to a JSON file at path.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).write_json("out.json")
```

### `write_parquet(path)`

Write the frame to a Parquet file at path.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).write_parquet("out.parquet")
```

### `write_tsv(path)`

Write the frame to a tab-separated file at path.

```
>>> dataframe({a: [1, 2], b: [3.0, 4.5]}).write_tsv("out.tsv")
```

## GroupBy methods

### `count(@col)`

The per-group row count, as a frame of keys plus the aggregate.

**Note:** Counts rows per group INCLUDING missing values in the column.

```
>>> dataframe({k: ["a","a","b"], v: [1,2,3]}).group(@k).count(@v).sort(@k).column("v")
[2, 1]
```

### `max(@col)`

The per-group maximum of one column, as a frame of keys plus the aggregate.

```
>>> dataframe({k: ["a","a","b"], v: [1,2,3]}).group(@k).max(@v).sort(@k).column("v")
[2, 3]
```

### `mean(@col)`

The per-group mean of one column, as a frame of keys plus the aggregate.

```
>>> dataframe({k: ["a","a","b"], v: [1,2,3]}).group(@k).mean(@v).sort(@k).column("v")
[1.5, 3.0]
```

### `min(@col)`

The per-group minimum of one column, as a frame of keys plus the aggregate.

```
>>> dataframe({k: ["a","a","b"], v: [1,2,3]}).group(@k).min(@v).sort(@k).column("v")
[1, 3]
```

### `std(@col)`

The per-group standard deviation of one column.

**Note:** SAMPLE std (n-1 divisor), unlike Array .std() (population); a 1-row group gives missing.

```
>>> dataframe({k: ["a","a","b"], v: [1,2,3]}).group(@k).std(@v).sort(@k).column("v")
[0.7071067811865476, missing]
```

### `sum(@col)`

The per-group sum of one column, as a frame of keys plus the aggregate.

```
>>> dataframe({k: ["a","a","b"], v: [1,2,3]}).group(@k).sum(@v).sort(@k).column("v")
[3, 3]
```

## Dict methods

### `contains(k)`

True when the key is present (alias of has).

```
>>> {"a": 1}.contains("a")
true
```

### `count()`

The number of entries (alias of length).

```
>>> {"a": 1, "b": 2}.count()
2
```

### `expect(k)`

The value for a key, raising when it is absent (the loud companion to get).

```
>>> {"a": 1, "b": 2}.expect("b")
2
```

### `get(k)`

The value for a key, or missing when absent (so `.get(k) ?? default` works).

```
>>> {"a": 1, "b": 2}.get("a")
1
```

### `has(k)`

True when the key is present (alias of contains).

```
>>> {"a": 1}.has("z")
false
```

### `insert(k, v)`

A new dict with the pair added (replacing k's value); the original is unchanged.

```
>>> {"a": 1}.insert("b", 2)
{"a" => 1, "b" => 2}
```

### `items()`

All (key, value) tuples as an array, in sorted key order.

```
>>> {"a": 1, "b": 2}.items()
[("a", 1), ("b", 2)]
```

### `keys()`

All keys as an array, in sorted key order.

```
>>> {"a": 1, "b": 2}.keys()
["a", "b"]
```

### `length()`

The number of entries (alias of count).

```
>>> {"a": 1, "b": 2}.length()
2
```

### `remove(k)`

A new dict without the key (absent key is a no-op); the original is unchanged.

```
>>> {"a": 1, "b": 2}.remove("b")

```

### `values()`

All values as an array, in sorted key order.

```
>>> {"a": 1, "b": 2}.values()
[1, 2]
```

## Net methods

### `accept()`

Blocks until a client connects; returns a connection carrying one parsed request.

```
>>> listener.accept()
```

### `accept_poll()`

Non-blocking accept of a persistent keep-alive connection; missing when none waits.

```
>>> listener.accept_poll()
```

### `clear()`

Empties the cookie jar.

```
>>> jar.clear()
```

### `close()`

Abandons an http_stream early, closing the socket now; idempotent.

```
>>> stream.close()
```

### `cookies()`

Each cookie in the jar as a record {name, value, domain, path}, in jar order.

```
>>> jar.cookies()
```

### `is_open()`

Whether a keep-alive connection is still open (peer not gone, not dropped).

```
>>> conn.is_open()
```

### `next()`

The next line/chunk of an http_stream body as a string; missing at end of stream.

```
>>> stream.next()
```

### `poll()`

Non-blocking accept: a connection if a client is already waiting, else missing.

```
>>> listener.poll()
```

### `poll_request()`

Non-blocking read: the next request once a whole one has arrived, else missing.

```
>>> conn.poll_request()
```

### `request()`

The connection's parsed request record {method, path, query, headers, body}.

```
>>> conn.request()
```

### `respond(response)`

Sends the reply: a record with {status, json, html, text}, a string, or JSON.

```
>>> conn.respond({status: 200, json: data})
```

### `send(event)`

Writes one SSE event without blocking; false means the client left or fell behind.

```
>>> conn.send(update.to_json())
```

### `sse()`

Begins a Server-Sent-Events response on the connection; then send one event at a time.

```
>>> conn.sse()
```

### `status()`

The HTTP status code of an http_stream response (e.g. 200).

```
>>> stream.status()
```

### `wait(conns, timeout_ms)`

Blocks until a client arrives, any conn in conns is readable, or the timeout ends.

```
>>> listener.wait(conns, 50)
```

## Headers methods

### `contains(name)`

True when a header with that name is present (alias of has, ignores case).

```
>>> headers([("Content-Type", "text/html")]).contains("Accept")
false
```

### `count()`

The number of header lines, repeats included (alias of length).

```
>>> headers([("Set-Cookie", "a=1"), ("Set-Cookie", "b=2")]).count()
2
```

### `get(name)`

The FIRST value for a header name (lookup ignores case), or missing.

```
>>> headers([("Content-Type", "text/html")]).get("content-type")
text/html
```

### `get_all(name)`

Every value for a header name (ignoring case), in arrival order.

```
>>> headers([("X-Tag", "a"), ("x-tag", "b")]).get_all("x-tag")
["a", "b"]
```

### `has(name)`

True when a header with that name is present (lookup ignores case).

```
>>> headers([("Content-Type", "text/html")]).has("CONTENT-TYPE")
true
```

### `items()`

All (name, value) tuples in wire order, names as they arrived.

```
>>> headers([("Content-Type", "text/html"), ("X-Id", "7")]).items()
[("Content-Type", "text/html"), ("X-Id", "7")]
```

### `keys()`

The header names exactly as they arrived, in wire order.

```
>>> headers([("Content-Type", "text/html"), ("X-Id", "7")]).keys()
["Content-Type", "X-Id"]
```

### `length()`

The number of header lines, repeats included (alias of count).

```
>>> headers([("Content-Type", "text/html")]).length()
1
```

### `to_dict()`

The headers as a plain Dict, giving up wire order and repeated names.

**Note:** Keys are LOWERCASED and the FIRST occurrence wins (matching get); repeats are dropped.

```
>>> headers([("X-Tag", "one"), ("x-tag", "two")]).to_dict()
{"x-tag" => "one"}
```

### `values()`

The header values in wire order.

```
>>> headers([("Content-Type", "text/html"), ("X-Id", "7")]).values()
["text/html", "7"]
```
